# 🎮 Tic-Tac-Toe JS

A simple, browser-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript. This project was developed as part of my journey through [The Odin Project](https://www.theodinproject.com/), focusing on DOM manipulation and game logic fundamentals.

## 🚀 Live Demo

Check out the live version here: [Tic-Tac-Toe JS](https://mubanga-1.github.io/tic-tac-toe-JS/)

## 🛠️ Features

* Two-player gameplay (Player X and Player O)
* Interactive 3x3 grid with click-based input
* Real-time win/draw detection
* Game reset functionality

## 📂 Project Structure

```
tic-tac-toe-JS/
├── index.html     # Main HTML file
├── styles.css     # Styling for the game
└── script.js      # Game logic and interactivity
```

## 🧑‍💻 How to Play

1. Clone the repository:

   ```bash
   git clone https://github.com/mubanga-1/tic-tac-toe-JS.git
   ```
2. Navigate to the project directory:

   ```bash
   cd tic-tac-toe-JS
   ```
3. Open `index.html` in your preferred web browser.

## 🎯 Gameplay Instructions

* Players take turns clicking on empty squares to place their symbol (X or O).
* The first player to align three of their symbols horizontally, vertically, or diagonally wins.
* If all squares are filled without a winner, the game ends in a draw.
* Click the "Restart" button to play again.
